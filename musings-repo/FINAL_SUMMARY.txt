🌐 DEPLOY:

   1. Push to GitHub:
      git init
      git add .
      git commit -m "Initial commit"
      git remote add origin <your-repo-url>
      git push -u origin main

   2. Deploy to Vercel:
      - Go to vercel.com
      - Import your GitHub repo
      - Click Deploy!

   OR

   2. Deploy to Netlify:
      - Go to netlify.com
      - Import your GitHub repo
      - Build: npm run build
      - Publish: .next

   ├── app/                    Next.js app directory
   │   ├── [category]/[slug]/  Dynamic routes for musings
