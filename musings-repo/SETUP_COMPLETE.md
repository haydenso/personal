## 🚀 Quick Start

```bash
cd /tmp/musings
npm install
npm run dev
```

## 📝 Add Content

Create `.mdx` files in `content/musings/`:

```mdx
---
title: My Note
author: Your Name  
date: January 19, 2025
category: notes
pinned: false
---

Your content here...
```

## 🎨 Customize

Edit `config.ts` to change:
- Site title & description
- Author name
- Category colors
- UI colors (selected highlight, background)
- Footer text

## 📦 Deploy

1. Push to GitHub
2. Connect to Vercel or Netlify
3. Auto-deploys on push!
