# Welcome to Your Personal Musings

This is your Apple Notes-style website for personal notes and musings!

## Features

- **Clean, minimalist design** inspired by Apple Notes
- **Category organization** with color-coded badges
- **Markdown support** with full formatting capabilities
- **Math rendering** using KaTeX: $E = mc^2$
- **Responsive design** that works on mobile and desktop

## Getting Started

1. Add your `.mdx` files to `content/musings/`
2. Customize `config.ts` with your preferences
3. Run `npm run dev` to see your musings

### Frontmatter Options

Each musing can have the following frontmatter:

- `title`: The title of your musing
- `author`: Your name
- `date`: Publication date
- `lastUpdated`: Last update date (optional)
- `pinned`: Pin to the top (true/false)
- `category`: Category name (matches your config)

## Formatting Examples

You can use **bold**, *italic*, ~~strikethrough~~, and `inline code`.
